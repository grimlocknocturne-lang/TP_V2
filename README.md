# BUT972-info-2-R304-QualiteDev

## Description

pluvio est un outil Python en ligne de commande qui lit des relevés de
pluie au format CSV et calcule des statistiques (total, moyenne et maximum).
Il permet de filtrer les relevés par commune ou par mois, et d'afficher
les totaux par commune. Il s'adresse aux personnes qui souhaitent
explorer et tester un petit jeu de données météorologiques fictives.

## Prérequis
- Python 3.10 ou une version plus récente
- Git pour cloner le dépôt
- pytest pour exécuter les tests
